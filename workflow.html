UE Log Analyzer — Tool Workflow

End-to-end data flow from raw Unreal Engine .log file to structured report

Input
📄 UE Log File (single)
A raw Unreal Engine .log file passed directly to the CLI.
MyProject.log
📄📄 Two Log Files (diff mode)
A before and after log file for regression comparison via the diff subcommand.
before.log after.log
CLI Entry Point
⌨️ CLI — python -m src.main
Click group with two subcommands: analyze (single log) and diff (two logs).
Flags: --output console|html|json, --severity, --category, --since, --until, --hitch-threshold, --shader-threshold, --watch, -o / --out-file.
src/main.py
Configuration (optional)
⚙️ Config Loader — load_config()
Walks ancestor directories looking for .ue-log-analyzer.toml. Merges discovered config with CLI flags (CLI wins). Provides [thresholds], [defaults], and [categories.aliases].
src/config.py .ue-log-analyzer.toml
Parsing
🔍 State-Machine Parser
Reads the log line-by-line using UE's timestamp+category regex. Handles: standard log lines, header-less continuations, multi-line crash blocks. Emits a ParseResult containing LogEntry[] and CrashBlock[]. Streams a Rich progress bar to the terminal during parsing.
src/parser.py src/models.py src/utils.py
Filtering
🔧 Filter Engine — apply_filters()
Applies FilterOptions derived from CLI flags to LogEntry[]. Filters by: severity level, category allowlist, time window (--since / --until). Crash blocks are always preserved regardless of filters.
src/filters.py
Analysis — run_all() orchestrates all analyzers → AnalysisReport
💥 Crash
Enriches crash blocks with exception type, source file & line number.
crash.py
⚠️ Errors & Warnings
Deduplicates by message template; counts occurrences per unique issue.
errors.py
📦 Assets
Detects missing references, load failures, and cook errors.
assets.py
🎨 Shaders
Compile errors and slow compilations above configurable threshold.
shaders.py
⏱️ Performance
Hitches, GC purges, OOM events — all with configurable thresholds.
performance.py
🌐 Network
Packet loss, timeouts, disconnects, and socket errors.
network.py
📅 Timeline
Builds a chronological event timeline sorted by log line number.
timeline.py
📊 runner.py
Orchestrates all analyzers and assembles the final AnalysisReport.
runner.py
Report Generation
🖥️ Console Report
Colored Rich terminal output. Summary panel, collapsible sections per analyzer category.
report/console.py
🌐 HTML Report
Self-contained dark-theme HTML via Jinja2. Collapsible sections, no external dependencies.
report/html.py
📋 JSON Export
Full structured JSON of the AnalysisReport for downstream tooling or CI.
report/json_export.py
Output
💬 Terminal
Printed directly to stdout with Rich color and formatting.
📁 File
Written to a file path via -o / --out-file. HTML or JSON.
🔌 VS Code
VS Code tasks + extension scaffold surface reports inside the editor.
Advanced Features
👁️ Watch Mode — --watch
Polls the log file for mtime changes via poll_until_changed(). Re-runs the full analysis pipeline automatically on every change. Ideal for monitoring a live session.
src/watcher.py
🔀 Diff Mode — diff before.log after.log
Runs the full pipeline on both logs, then compute_diff() computes per-section added/removed/delta. Exits with code 1 on regressions (useful in CI). Outputs a DiffReport to console or JSON.
src/diff.py report/diff_console.py report/diff_json.py
